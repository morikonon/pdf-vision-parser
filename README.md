# PDF Table Extractor (VLM-based)

Микросервисный пайплайн для точного извлечения сложных финансовых таблиц из PDF-документов с использованием Vision-Language Models (VLM).

## Проблема и Решение
Классические OCR-решения (pdfplumber, Tesseract, docling) часто теряют структуру при парсинге банковских выписок и отчетов из-за слипшегося текста, отсутствия четких границ колонок и сложной иерархии (вложенные строки).

**Данное решение** использует мультимодальный подход:
Вместо посимвольного парсинга страницы рендерятся в изображения и отправляются в модель **GPT-5.4-nano**. Модель визуально анализирует структуру и возвращает строго форматированный CSV. Это дает ~99% точности на сложных финансовых таблицах и автоматически фильтрует нерелевантный контент (оглавления, абзацы текста).

## Ключевые фичи архитектуры
* **Concurrency (Многопоточность):** Использование `ThreadPoolExecutor` для параллельной отправки страниц в API. I/O операции не блокируют друг друга.
* **Resilience (Отказоустойчивость):** Интеграция `tenacity`. Декораторы с экспоненциальной задержкой защищают пайплайн от сетевых сбоев и ошибок лимитов (RateLimit 429).
* **Data Validation:** Строгая проверка ответов LLM через `pandas.read_csv` перед сохранением на диск. Битые структуры отбрасываются.
* **Cost Efficiency:** Использование `gpt-5.4-nano` снижает стоимость парсинга до копеек за десятки страниц, сохраняя SOTA-качество извлечения данных.

## Структура проекта
```text
pdf_table_extractor/
├── input/              # Директория для исходных PDF файлов
├── output/             # Директория для извлеченных CSV (создается автоматически)
├── src/                
│   ├── config.py       # Централизованные настройки и промпты
│   ├── logger.py       # Настройка colorlog
│   ├── pdf_worker.py   # Рендеринг PDF -> Base64 (PyMuPDF)
│   ├── llm_client.py   # Инкапсуляция логики OpenAI API + Retry
│   └── validator.py    # Валидация структуры данных (pandas)
├── main.py             # Точка входа и оркестратор потоков
├── .env                # Переменные окружения (API ключи)
└── requirements.txt    # Зависимости
```

## Установка и запуск

**1. Клонирование и установка зависимостей:**
```bash
git clone <твой-репозиторий>
cd pdf_table_extractor
python3 -m venv venv
source venv/bin/activate  # Для Windows: venv\Scripts\activate
pip install -r requirements.txt
```

**2. Настройка окружения:**
Создайте файл `.env` в корне проекта и добавьте ваш API ключ OpenAI:
```text
OPENAI_API_KEY=sk-твоя_секретная_апи_строка
```

**3. Использование:**
Положите ваш целевой PDF файл в папку `input/`.
В файле `main.py` укажите имя файла:
```python
if __name__ == "__main__":
    main("your_file.pdf")
```
Запустите скрипт:
```bash
python3 main.py
```
Результаты появятся в папке `output/your_file/` в виде отдельных валидных `.csv` файлов.

## ⚙️ Конфигурация (src/config.py)
Вы можете гибко настраивать пайплайн без изменения основного кода:
* `MODEL_NAME`: Смена модели (например, на `gpt-5.4-mini`).
* `MAX_WORKERS`: Количество параллельных потоков (регулируйте в зависимости от Tier вашего ключа OpenAI).
* `DPI`: Качество рендера (по умолчанию 200).
